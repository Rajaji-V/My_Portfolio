# Rajaji's Portfolio

A modern, responsive portfolio website showcasing my skills, projects, and experience as an aspiring full-stack developer. Built with HTML, CSS, and JavaScript, featuring smooth animations and a modern UI for an engaging user experience.

---

## 🚀 Features

- **Responsive Design** – Optimized for all screen sizes (mobile-first).
- **Smooth Animations** – Fade-ins, hover effects, typing animation, and scroll-based animations.
- **Interactive Elements** – Smooth scrolling navigation, hamburger menu, and dynamic profile links.
- **Well-Structured Sections** – Hero, About, Education, Profiles, Skills, Experience, Projects, Contact, and Footer.
- **Modern UI** – Gradient backgrounds, shadows, and transitions for a professional look.

---

## 🛠 Technologies Used

- **HTML5** – Structure and content  
- **CSS3** – Styling, animations, and responsiveness  
- **JavaScript** – Interactivity and animations  
- **Font Awesome** – Icons  
- **Google Fonts** – Poppins font family
